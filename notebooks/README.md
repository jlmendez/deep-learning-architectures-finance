# Deep-learning notebook

The source notebook covered MLP, CNN, recurrent networks, LSTM/GRU and attention/Transformers. The portfolio version decomposes these ideas into reusable Python modules and uses `deep_learning_architecture_comparison.ipynb` as the experimental entry point.

`src/attention_transformer.py` remains the dedicated attention/Transformer implementation; the additional modules make the MLP and recurrent paths equally visible.
